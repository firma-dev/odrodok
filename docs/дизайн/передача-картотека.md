# Картотека: передача исполнителям

Сайт odrodok.ru переделывается в картотеку документальных работ Виктора:
каждый фильм — бумажная учётная карточка в стопке. Дизайн — Орвин, «картотека».
Этот файл — выжимка холста и записки, чтобы не перечитывать их целиком.
Ветка каркаса: `vrx/kartoteka` (от `main` c290b80).

**Не пушить никуда.** Любой push в `main` автоматически выкладывает сайт
(`.github/workflows/deploy.yml`). Workflow не менять.

## 2. Механика (из записки, сверено с кодом холста)

1. **Первый экран.** Фото Виктора отпечатком на скотче, под ним знак, справа
   имя и три абзаца. Сверху видна нижняя кромка стопки (44 px) и «↓ потяните».
2. **Открытие.** Клик по «потяните», прокрутка вниз, свайп вниз, стрелка ↓/→ или
   тянуть рукой (отпустил при p > .25 — открылась). Стопка выпадает сверху
   1,3 с, в конце «посадка» 3 px. При **первом** открытии ярлыки задних
   выезжают по одному и играет шелест. Первый экран гаснет сразу, проявляется
   при закрытии с задержкой 1,1 с.
3. **Листание.** Колесо (порог 6, не чаще 800 мс), стрелки, свайп (> 50 px),
   рука (> 150 px). Передняя падает вниз, следующая уже лежит. Ряд ярлыков
   сдвигается влево, справа проявляется следующий. Назад — наоборот. Клик по
   ярлыку — сразу к карточке. Прокрутка вверх на первой карточке — закрыть.
4. **Карточка.** Обложка на фотоуглах, справа поля и описание, красная пометка
   карандашом. Внизу «Смотреть» и «Кадры», справа «лист 01 / 08 · одродок».
5. **Смотреть.** Переворачивается только обложка, на обороте плеер. Кнопка
   становится «■ Стоп», по ней обложка возвращается. Пробел — то же.
6. **Кадры.** Переворачивается вся карточка: кадр в окне и миниатюры, лента
   едет вертикально, по миниатюрам ездит рамка. «↺ К обложке» и Esc — назад.
   Плеер остаётся на обложке.
7. **Пока открыт плеер или кадры — листание стоит.**
8. **Верхняя панель**: «✕ Закрыть» (оранжевая), переключатель «сначала новые /
   старые» (по умолчанию новые), иконка звука. Появляется, когда стопка доехала
   (задержка 2,2 с при первом открытии, 1,2 с потом).
9. **Поля экрана**: слева вертикально «виктор сивак · одродок», справа живые
   часы `(02.10.26) 13:44:02`.
10. **Закрытие** возвращает на первый экран, позиция в стопке сохраняется;
    повторное открытие — без каскада ярлыков.
11. **Сортировка**: стопка гаснет .25 с, перекладывается, проявляется на первой.
12. **Больше 9 работ**: видны 9 (передняя + 8), дальше — opacity 0; ряд ярлыков
    из 9 слотов сдвигается.
13. **Адрес** `odrodok.ru/<slug>` открывает сразу эту карточку (в записке —
    «что осталось»). Отдаёт `.htaccess` в корне: `/<slug>` → index.html,
    старые `/pervoprohodcy` и `/vozduh` → свои .html, `/<slug>/` → 301 без косой.

## 4. Токены

В `css/база.css`, `:root`. Старый `assets/tokens.css` (IDS) картотека **не**
подключает — там другие цвета карточки.

| токен | значение | где |
|---|---|---|
| `--paper` | #F2ECE0 | фон страницы |
| `--card` | #F8F3E8 | бумага карточки |
| `--ink` | #171512 | текст, активный ярлык |
| `--redline` | rgba(226,69,28,.62) | красная черта |
| `--rule` | rgba(70,90,140,.15) | синие линейки |
| `--pencil` | #B8341A | пометки |
| `--sign` / `--sign2` | #E2451C / #DC4A1E | «Закрыть», шкала плеера |
| `--ph` | #E9E2D4 | место под картинку, которой нет |

Шрифты: OCR-A — весь текст, только заглавными; Amatic SC 700 — временно для
пометок до сканов почерка. **Лёгкий вариант для Safari** (решение брифа, отличие
от холста): без `-webkit-text-stroke` (утолщение ~30 % запечено в
`ocra-bold.woff2` — это основной вес, `font-weight:700`), без `text-shadow`,
краска машинки (`background-clip:text`) только на имени; бумага и зерно —
одна запечённая текстура `бумага-зерно.webp`, умножается на цвет через
`background-blend-mode` внутри элемента; без `mix-blend-mode` и слоя зерна поверх всего.

## 5. Анимации (тоже токенами в `база.css`)

Как механизм, с весом: без пружин и зума, только `transform` и `opacity`.

| движение | время и кривая | токены |
|---|---|---|
| стопка выпадает / уходит | 1.3s (.62,.02,.18,1); посадка 3 px за .22s (.3,0,.2,1), только первое открытие | `--t-stack --e-stack --t-seat --e-seat` |
| ярлыки при первом открытии | top .4s (.3,.6,.2,1), задержка 400 + (n−1)·220 мс | `--t-tabs --e-tabs` |
| карточка уходит вниз | .72s (.5,.02,.8,.38), rotateX(−14°), сдвиг 1700 px | `--t-fall --e-fall` |
| карточка возвращается | .9s (.15,.75,.3,1) | `--t-back --e-back` |
| сдвиг ряда ярлыков | left .6s (.7,0,.22,1) .12s; новый — opacity .45s .35s | `--t-row --e-row --t-rowin` |
| переворот обложки | .9s, середина translateZ(70px); до 90° (.55,0,.85,.5), после (.15,.5,.45,1); стороны прячутся visibility на .45s | `--t-cover --e-flip1 --e-flip2` |
| переворот карточки | 1s, translateZ(40px), те же кривые; visibility на .5s | `--t-flip` |
| свет на перевороте | сторона темнеет к 50 % хода | `.light` |
| лента кадров, рамка | .6s (.68,0,.2,1.04) | `--t-strip --e-strip` |
| затемнение задних | opacity .8s ease, min(.06·d, .3) | `.shade` |

Вложенный 3D-переворот ломается — каждая сторона дополнительно скрывается через
`visibility` ровно на середине хода. `prefers-reduced-motion` — всё мгновенно
(одно правило в конце `база.css`).

## 6. Звук

Включён по умолчанию, иконка выключает; играть можно только после первого
действия пользователя. Записи Виктора (Artlist), моно. Высота каждый раз ±4 %.

| событие | звук (файл) | громкость |
|---|---|---|
| открытие | шелест целиком, 3,1 с (`open`) | .55 |
| закрытие | начало шелеста, 0,75 с (`close`) | .5 |
| любая кнопка | двойной щелчок машинки, 1,5 с (`btn`) | .8 |
| переход колесом/свайпом/клавишами | одна из 7 страниц книги, без повтора подряд (`page0`…`page6`) | .5 |
| переворот с клавиатуры | страница книги (`flip`) | .6 |

С кнопки — только щелчок, без звука действия (кроме шелеста открытия/закрытия,
он идёт через .16 с).

## 8. Модель, шина, шаблон карточки

### Сцена
Геометрия — пиксели холста. `.stage` 1440×900 (при ширине окна ≤ 767 px —
390×844) масштабируется целиком `scale(var(--k))`, `--k = min(окно/сцена)`.
Ставит `js/данные.js`, шлёт `od:resize`. Поля экрана (`.rail`) — вне сцены,
у краёв окна. Раскладка телефона — `@media (max-width:767px)`.

### `window.OD` (js/данные.js)

| что | зачем |
|---|---|
| `OD.works` | работы в порядке описи (`order` ↑) |
| `OD.state` | `{open, opened, sort:'new'|'old', index, sound}`; части могут добавить свои ключи (например `flip`) |
| `OD.set(patch)` | менять состояние только так: обновит `<body data-open/-sort/-sound>` и пошлёт `od:state` |
| `OD.ordered()` | работы в текущем порядке («новые» — обратный порядок описи) |
| `OD.bySlug(slug)` | `{work, index}` в текущем порядке или `null` |
| `OD.card(w, i, n)` | собрать `<article class="c">` из шаблона |
| `OD.render()` | положить все карточки в `#stack-seat` в текущем порядке, `z-index` и `--d` начальные; шлёт `od:rendered` |
| `OD.on(type, fn)` / `OD.emit(type, detail)` | шина: `CustomEvent('od:'+type)` на `document` |
| `OD.stage` | `{k, phone}` |
| `OD.PH` | тексты заглушек |

### События

| событие | кто шлёт | detail |
|---|---|---|
| `od:data` | данные | `{works}` |
| `od:rendered` | данные | `{count}` |
| `od:state` | данные (по `OD.set`) | `{patch, state}` |
| `od:resize` | данные | `{k, phone, changed}` |
| `od:button` | данные (любой клик по `<button>`, раньше действия) | `{el, action}` |
| `od:open` | стопка | `{first, via}` |
| `od:close` | стопка | `{via}` |
| `od:arrived` | стопка | — (стопка доехала: панель) |
| `od:go` | стопка | `{from, to, via:'wheel'|'key'|'swipe'|'drag'|'tab'|'url'}` |
| `od:sort` | стопка | `{order}` |
| `od:flip` | переворот | `{target:'cover'|'card', on, via:'button'|'key'}` |
| `od:shot` | переворот | `{index, via}` |
| `od:sound` | звук | `{on}` |

Скрипты подключены `defer` в порядке: данные, стопка, переворот, звук, телефон.
`данные.js` стартует на `DOMContentLoaded` — к этому моменту все части
подписаны. `od:data` и `od:rendered` приходят после загрузки JSON.

### Шаблон карточки — `<template id="tpl-card">` в index.html


- `data-depth` = i − index: 0 — передняя, дальше 1, 2…, у ушедших вниз
  **отрицательный**. `--d` = 0…9 (у ушедших 0). Ставит стопка; `OD.render()` —
  начальные. От `--d` зависят место ярлыка (`translate` в `стопка.css`, не
  `left/top`) и затемнение `.shade`. Передняя: `.c[data-depth="0"]`.
- Классы стопки (подробно — шапка `css/стопка.css`):

  | класс | когда |
  |---|---|
  | `body.is-first` | первое открытие: каскад ярлыков (2,5 с) |
  | `body.is-moving` | стопка едет (открытие/закрытие) |
  | `body.is-arrived` | стопка доехала (1,3 с) — видна панель |
  | `body.is-instant` | прямой заход по адресу — всё сразу на месте |
  | `.stack.is-drag` | стопку тянут рукой |
  | `.stack.is-fading` | смена порядка: стопка гаснет .25 с |
  | `.stack.is-instant` | перекладка: без переходов на один кадр |
  | `.stack-seat.is-seat` | «посадка» 3 px после первого открытия |
  | `.c.is-gone` | ушла вниз (data-depth < 0); в покое скрыта |
  | `.c.is-falling` / `.c.is-rising` | уходит вниз / возвращается |
  | `.c.is-drag` | карточку тянут рукой, transform инлайном |
  | `.c.is-held` | прыжок назад через ярлык: промежуточные стоят без лица, видны ярлыки |
  | `.c.is-near` | окно ±2 от передней: постоянный слой (will-change) |
  | `.c.is-deep` | дальше 2 за передней: без 3D-слоёв |
  | `.c.is-far` | d ≥ 9: не видна (opacity 0) |
  | `.c.is-off` | d ≤ −3 или d ≥ 10: display:none |

  **Важно переворот/телефону:** у `.c.is-deep` стопка ставит `.flip` и
  `.cover-flip` в `transform-style:flat`, `backface-visibility:visible` и
  `display:none` у `.face.back` и `.cover-back` — оборотов у дальних карточек
  нет. Переворачивать можно только переднюю (она всегда `.is-near`).
- Классы переворота: `.c.is-playing`, `.c.is-frames`. Новые — дописать сюда.
- Кнопки: `data-action` = `open | close | sort (data-sort) | sound | pick |
  watch | frames | to-front | shot-prev | shot-next | shot (data-n)`.

### Заглушки
Пустое поле в JSON — `null`. Показ (`OD.show`):
`[тип] · [хрон.] · [статус]`, `в картотеке с [дата]`, поля — `[подпись]`
(`[герои]`, `[место]`…), описание — `[Описание фильма в две-три строки: о чём он
и почему попал в картотеку.]`, пометка — `note`, иначе `status`, иначе `[статус]`
(как на холсте). Картинка не загрузилась — `[обложка №N — нужен файл]`; нет
кадров — 6 заглушек из обложки в сером с `[кадр n — нужен файл]`.
Подписи полей по умолчанию: герои, место, даты, вместе с; у отдельных карточек
свои (с холста) — `labels` в JSON.

## 9. Файлы (assets/kartoteka/) — по факту

## 10. Данные

`data/работы.json` собирается из описи: `tools/опись-в-json.py`.
Как обновить, когда владелец дописал опись:

1. агент: ArtifactData `list`, url описи, `collection: works`,
   `query: {"limit":100}`, `out_dir: <папка>` — по файлу на работу;
2. `python3 tools/опись-в-json.py <папка>/works` (`--check` — только показать);
3. скрипт печатает пустые поля и одинаковые номера; новые работы без строки в
   таблице `ХОЛСТ` (адрес, ярлык, подписи) получают адрес `rabota-<id>` —
   дописать таблицу.

Поля работы: `id, slug, order, no, title, type, duration, status, added, place,
dates, people, authors, cycle, link, desc, note` (как в описи, пустые — `null`,
текст прогнан типографом), `short` (ярлык), `labels` (подписи полей),
`cover` (780w), `cover_srcset` (780w/1560w) и `shots` (пути), `src` (id вложений в описи).
Порядок «новые» — обратный порядок описи (`order`). Номера скрипт не правит.

Типограф: `python3 tools/nbsp.py index.html` — после правок текста в разметке.

## 11. Проверка каркаса

Локально: `python3 -m http.server 8731 --bind 127.0.0.1` в корне, открыть
`http://127.0.0.1:8731/`. JSON грузится через `fetch` — из файла (`file://`)
страница не откроется. Снимки приёмки — `приёмка/снимки/<часть>/`, не в git
(`приёмка/.gitignore`).
