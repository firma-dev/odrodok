# Как подключить GitHub — по шагам

Репозиторий уже создан локально, два коммита сделаны. Осталось завести аккаунт,
залить код и включить автодеплой. Дальше правки будут выкладываться сами:
меняешь файл → `git push` → через минуту сайт обновился.

---

## 1. Аккаунт на GitHub

1. Открыть <https://github.com/signup>
2. Почта, пароль, имя пользователя (например `viktorsivak`), подтвердить почту.
3. Тариф — Free, его хватает с запасом.

## 2. Проверить, что git есть на компьютере

Открыть Терминал (Cmd+Space → «Терминал») и выполнить:

    git --version

Если версия вывелась — всё есть. Если macOS предложит установить
«Инструменты командной строки» — согласиться и дождаться установки.

Затем один раз представиться (эти данные попадают в историю коммитов):

    git config --global user.name "Viktor Sivak"
    git config --global user.email "viktor.m.sivak@gmail.com"

## 3. Создать репозиторий на GitHub

1. <https://github.com/new>
2. **Repository name:** `odrodok`
3. **Private** — если не хочешь, чтобы код видели посторонние (сайт всё равно
   останется публичным, приватность касается только исходников).
4. Ничего не отмечать в «Initialize this repository» — код уже есть локально.
5. Кнопка **Create repository**.

## 4. Залить код

В Терминале:

    cd ~/Desktop/одродок/site
    git branch -M main
    git remote add origin https://github.com/ИМЯ_ПОЛЬЗОВАТЕЛЯ/odrodok.git
    git push -u origin main

`ИМЯ_ПОЛЬЗОВАТЕЛЯ` заменить на своё.

При первом push спросят логин и пароль. **Вместо пароля нужен токен:**
<https://github.com/settings/tokens> → Generate new token (classic) →
поставить галочку `repo` → скопировать и вставить в терминал вместо пароля.
Токен показывается один раз — сохрани его в менеджере паролей.

## 5. Включить автодеплой на хостинг

В репозитории уже лежит `.github/workflows/deploy.yml`. Ему нужны доступы к FTP.

Сначала возьми данные FTP в панели reg.ru:
ISPmanager → **FTP-пользователи**. Там логин; если пароля не помнишь —
можно задать новый через «Изменить».

Затем в GitHub: репозиторий → **Settings** → **Secrets and variables** →
**Actions** → **New repository secret**. Добавить четыре штуки:

| Имя | Значение |
|---|---|
| `FTP_SERVER` | `server68.hosting.reg.ru` |
| `FTP_USERNAME` | логин FTP-пользователя |
| `FTP_PASSWORD` | его пароль |
| `FTP_DIR` | `/www/odrodok.ru/` |

После этого любой `git push` будет сам выкладывать сайт.
Ход выкладки видно во вкладке **Actions**.

## Как работать дальше

Изменил файлы — сохранил их. Потом в Терминале:

    cd ~/Desktop/одродок/site
    git add -A
    git commit -m "коротко, что поменял"
    git push

Через минуту изменения на сайте.

Полезное:

    git log --oneline        история изменений
    git diff                 что изменено с последнего коммита
    git checkout -- файл     откатить файл к последнему коммиту

## Что НЕ попадает в репозиторий и на сайт

- `dist/` — архивы сборок (в `.gitignore`)
- `src/` — исходные тексты замыслов, черновики: лежат в репозитории для истории,
  но на сайт не выкладываются
- `tools/` — типограф, тоже только в репозитории
